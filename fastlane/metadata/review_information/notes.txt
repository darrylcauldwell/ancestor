QUICKEST PATH TO REVIEW (no file download or settings needed):

1. Launch the app.
2. On the welcome screen, click "View Sample Tree".
   — This creates and opens a "Sample Family" project containing a fictional
     30-profile Ashford family across 5 generations. The project persists, so
     you can close and reopen the app without losing it.
3. The sidebar now appears with all features available:
     • Tree — pedigree + descendants navigation
     • Audit — 18 consistency checks and gap detection
     • Research — the structured research pipeline
     • Leads — investigation queue
     • Settings — preferences, project management, backups
4. Click any person in the tree to expand details, navigate ancestors, or
   start research.

OPTIONAL: TEST GEDCOM IMPORT WITH A SAMPLE FILE

If you'd like to test the GEDCOM import path specifically, a sample .ged file
is hosted at:

  https://raw.githubusercontent.com/darrylcauldwell/ancestor/main/samples/ashford-demo.ged

The file is plain-text GEDCOM (.ged), which browsers display inline rather than
auto-download. To save it: right-click the link → "Save Link As..." (or
"Download Linked File"). Then in the app:

  - On the welcome screen click "Import GEDCOM (.ged or .gdz)…"
  - Select the saved ashford-demo.ged file
  - A new project is created containing the imported tree

OPTIONAL FEATURES (not required for core review):

- "Reasoning Model" downloads an open-source model (~4 GB) from Hugging Face
  on first use. No API key required but needs ~7 GB memory. Used for on-device
  disambiguation, next-search suggestion, and narrative synthesis. Runs entirely
  on-device via Apple MLX; no data leaves the device.

NETWORK USAGE

The app searches public genealogy websites with search parameters only
(surname, given name, year range). Your tree data is never uploaded. No
third-party AI APIs are used. No analytics, telemetry, or user accounts.
